## Собственный проект

Тема проекта: персонажи игры Dota 2

Главный класс:  **DotaHero**

### Почему этот объект нужен программе:
`DotaHero` описывает одного персонажа из игры: его имя, роль, запас здоровья и процент побед


### какие данные хранит объект:

- `Name` - имя персонажа (string)
- `Role` - роль в команде (string)
- `Health` - запас здоровья (int)
- `WinRate` - процент побед (double)
- `GamesPlayed` - сколько игр сыграно на герое (int, задаётся автоматически)

### Какие значения задаются через конструктор:
`Name`, `Role`, `Health`, `WinRate` — передаются при создании объекта

### Какие значения можно задавать автоматически:
`GamesPlayed` = 0 - при добавлении героя в свой пул логично, что вы на нем еще не играли, поэтому счетчик начинается с нуля


## Какое значение я решил задавать автоматически и почему?

`GamesPlayed` = 0: у нового персонажа по умолчанию нет сыгранных игр. Логично, что счетчик начинается с нуля. Это значение ставится автоматически, чтобы каждый раз не передавать ноль вручную.


## Практическая работа №2 (собственный проект)

Действие: `PlayMatches(int count)` — добавляет сыгранные матчи герою Dota 2.

Параметр: `count` — сколько матчей добавить.

Отказ: если `count <= 0`, метод завершается через `return;` и не меняет `GamesPlayed`.

Наблюдавшиеся значения: до вызова — `0`; после `PlayMatches(3)` — `3`; после `PlayMatches(-2)` — осталось `3`.
